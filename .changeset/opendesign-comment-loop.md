设计面板新增评论回路：评论侧栏（对当前产物发评论 / 线程内追加 / resolve 重开 / 失败态重试投递 / 四值投递徽标 / 损坏数据错误态）；评论数据落会话工作目录 `.od-comments/comments.json`（lock + 原子写，损坏读侧报错不重建）；评论作为独立来源消息（`source.kind='opendesign-design-mode/comment'`）回注当前会话，模型读产物源码改稿；写通道经宿主 connection.fetch 注册五条 `/api/opendesign-design-mode.comments` 路由（宿主 /api 共享鉴权层覆盖，落点双层包含校验）；`/opendesign-doctor` 扩为十二节，新增第⑫节评论环（线程计数 / 投递状态分布 / parse 健康度与恢复动作 / 路由族声明）；质量环监听排除 `.od-comments/`，两环互不误触。

评论升级为元素级锚点挂靠（原文件级挂靠形态随之扩展）：新建评论的唯一入口改为产物内拾取——预览产物上悬停高亮、点击选中弹出评论输入框（面板直发输入框移除，既有线程的追加 / resolve / 重试投递保留），评论带元素锚点落盘（三级降级：元素 id → `data-od-id` / `data-screen-label` 产物锚属性 → 结构路径，旧评论数据无锚点字段照常读取）；回注消息携带锚点选择器与「改稿写盘保留 id 与 data-od-id / data-screen-label 锚属性」指令，模型按锚点定位元素改稿，已有评论跨改稿存活；已评论元素在产物内钉编号徽章，侧栏条目与徽章点击均可滚动定位高亮，锚点失效（改稿后选择器不命中）时侧栏条目如实标注并禁用定位。

拾取脚本与产物预览的通道形态：产物伺服对 HTML 响应动态注入拾取脚本（磁盘产物字节不变；HEAD / 非 HTML / `.od-frames/` 设备壳路径不注入，壳内元素不可拾取），脚本与面板之间经 postMessage 桥收发（报文带版本与前缀、双向来源校验，不满足即静默忽略；iframe 沙箱属性保持 `allow-scripts` 不放同源）；产物改稿写盘后伺服响应 ETag 变化，面板版本探针（5 秒定时 + 聚焦恢复）感知后自动重挂预览并重建徽章；面板打开设计预览时自动收起宿主左侧边栏、关闭预览还原恰一次（面板头部「侧栏」按钮可手动开关，宿主无侧栏状态读取接口时按盲切换如实呈现）。
